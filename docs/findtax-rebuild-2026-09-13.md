# FindTax 정비 결과와 다음 우선순위

작업일: 2026-09-12~13. 범위는 메인 정돈, 확인된 계산 오류 수정, 블로그 품질 장치, 수익화 동선 정리다. 전체 세법 검수나 AdSense 승인 완료를 의미하지 않는다.

## 적용한 변경

| 영역 | 이전 | 변경 |
| --- | --- | --- |
| 메인 | 계산기 목록·지역 목록·상담·설명이 한 화면에 반복 | 4개 상황 진입, 가이드 2개, 상담 안내, FAQ로 정리 |
| 시작 | 상황 선택 후 추가 클릭 | 사업·부업 / 셀러 / 가족 증여 / 연금·노후에서 직접 이동 |

| 글 CTA | 부수 키워드 때문에 관계없는 계산기로 이동 | 주제 기준 매핑. 지원하지 않는 종부세·ISA 등은 전체 목록 안내 |
| 측정 | 블로그 클릭은 개별 API 호출 | 공통 GA4/내부 이벤트 함수 사용, 메인 4개 진입 클릭 추가 |

계산기는 기존 14개 URL을 유지한다. 연금·IRP는 납입 시 세액공제, 노후월급은 자산 인출·생활비 비교이므로 서로 대체할 수 없다. 증여세는 개별 증여 세액, 상속·증여 비교는 장기 시나리오 역할을 유지하되 공통 규칙부터 일치시킨다. 기능을 없애는 것보다 진입과 공통 계산을 정돈하는 접근이다.

## 콘텐츠 현황

- 고유 글 54개. 출처 연결 32개, 출처 보완이 필요한 보관 글 22개.
- 이번에 개별 내용을 개정한 글은 증여세 안내 1개다. 나머지 전체 글의 세무 검수를 완료했다고 주장하지 않는다.
- 보관 글은 기존 주소를 유지하고 noindex 및 주의문구를 제공한다. noindex는 AdSense 심사에서 제외된다는 뜻이 아니다.
- `npm run content:audit`는 우선순위·출처 상태·CTA 목적지를 출력한다. 사실 검증 자동화가 아니다.
- 최우선 후속 편집은 시행 전 세제개편안 글의 현재법/개정안 구분, 이어서 출처 없는 보관 글이다. 같은 URL에서 수정하고 실제 수정일만 갱신한다.

## 수익화: 먼저 측정할 퍼널

`가이드 열람 → 관련 계산기 진입 → 유효한 계산 완료 → 상담 폼 진입 → DB 접수 → 유효 상담 → 계약/정산`

홈 진입은 `home_entry_click`, 글 CTA는 `blog_cta_click`, 계산은 기존 calculator 이벤트를 사용한다. API의 `lead_submit`은 DB 저장 이후에 기록하는 구조를 확인했다. 그러나 접수는 매출이 아니다. 메일 알림·연락 성공·유효 상담·계약·정산까지의 실제 운영 결과는 이번에 검증하지 않았으며 가짜 상담을 전송하지 않았다.

| 우선순위 | 실행 | 완료 기준 |
| --- | --- | --- |
| 1 | 기존 관리자에서 접수 누락·중복·연락 가능 여부 점검 | 접수 ID 기준 DB/관리자/알림 일치, 테스트 데이터 분리 |
| 2 | 유효 상담·연락 완료·계약·취소·정산 상태 정의 | 담당자와 처리일, 증빙, 중복 및 취소 사유 기록 |
| 3 | 유입경로와 접수 ID를 개인정보 없이 연결 | 페이지뷰·클릭·접수·매출을 섞지 않는 전환표 |
| 4 | 검색 유입이 있는 핵심 글부터 개선 | 글별 계산기 진입률/접수율 비교, 같은 기간·동일 정의 사용 |
| 5 | 전문가 제휴 조건 검토 | 서비스 범위, 광고/소개/중개 법적 검토, 유효 건 정의, 정산 조건 합의 |
| 6 | 검증된 뒤 제한적으로 유료 유입 실험 | 지출 상한을 미리 정하고 순수익 기준으로 중단·확대 |

유효 상담 CPA = 집행비용 / 중복·스팸을 제외한 유효 상담 건수. 계약 CPA = 집행비용 / 실제 신규 계약 수. 손익분기 CPA는 실제 수취액에서 취소·환불·파트너 지급·변동 운영비를 뺀 금액으로 계산해야 한다. 계약이나 정산 데이터가 없으면 수익률을 추정값으로 표시하고 실제 성과처럼 쓰지 않는다.

초기에는 계산·가이드 무료 이용을 유지한다. 과도한 회원가입, 경고 문구, 상담 팝업, 고정 광고를 추가하지 않는다. AdSense는 보조 수익원이며 승인 전후로도 사용 목적과 콘텐츠 품질이 우선이다. 수수료율이나 매출 목표는 실제 전환·정산 데이터를 확보한 뒤 결정한다.

## 남아 있는 한계

1. 증여 계산은 과거 10년 합산·기납부세액·신고세액공제를 완전 정산하지 않는다. 화면과 글에 한계를 명시했다.
2. 증여 준비표 날짜는 기본 월말 기준이다. 공휴일·기한 연장을 자동 계산하지 않아 최종 기한 확인 안내를 추가했다.
3. 4대보험은 가입 자격·지원·개별 고지액을 대체하지 않는다. 국민연금 외 모든 보험 예외를 이번에 최신 검증한 것은 아니다.
4. 14개 계산기 전체를 세무전문가가 검수했다는 보증은 없다. 공제·감면·부동산 예외 등 고위험 항목은 공식 근거와 경계 테스트를 추가하는 후속 범위다.
5. 하위 계산기 페이지에는 과도한 설명·중복 상담·일률적인 기준 점검 문구가 남아 있다. 메인 다음 디자인 정비 대상으로 삼는다.
6. AdSense 승인 및 검색 노출 증가는 외부 심사·데이터 관찰이 필요한 결과다. 반복 재신청이나 기능 추가만으로 해결됐다고 보지 않는다.
