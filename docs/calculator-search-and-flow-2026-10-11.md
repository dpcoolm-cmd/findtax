# FindTax 계산기 검색·사용 흐름 점검 (2026-10-11)

## 확인한 사실

- 운영 계산기 15종과 목록 페이지 모두 HTTP 200, H1 1개, 자기 canonical, index 허용, 기존 사이트맵 포함. 원본: `calculator-search-before-2026-10-11.json`.
- Google Search Console `https://findtax.kr/` 속성: 10월 4일 집계 색인 1개 / 제외 360개. noindex 147, 크롤링 후 미색인 128, 발견 후 미색인 85. 현재 전체 사이트의 실시간 색인 개수를 뜻하지 않는다.
- 미색인 예시에 계산기 목록·예금적금·노후월급·취득세·부가세·1인사업자 페이지가 실제 포함됨.
- Google 실적 기본 3개월 보기: 노출 21, 클릭 1, CTR 4.8%, 평균 순위 12.5. 조회 당시 업데이트 약 57.5시간 전. 검색어 공개 행은 findtax 4회, 찾아줘 세무사 1회, 기타소득 계산기 1회 노출. 비공개 검색어 때문에 표 합계와 전체는 다를 수 있다.
- noindex 제외 147개를 전부 오류로 판단하지 않음. 지역·세무사 개별 페이지에는 품질 기준에 따른 의도적 noindex가 있다. 계산기 15종에는 현재 noindex가 없다.
- 코드로 15종의 입력·결과 구조 확인. 운영 브라우저에서는 부가세 공급가액 1,000,000원 입력 동작 확인. 모든 계산기를 모든 모바일 기종으로 검증한 것은 아니다.

## 이번 변경

1. 부가세: 검색 제목·설명을 실제 공급가액/세포함 총액 역산 기능에 맞춤. 매입공제 후 신고 납부세액 계산이라는 잘못된 약속 제거.
2. 종합소득세: 과세표준 기준 국세 산출세액임을 명시. 지방소득세까지 반영한다는 잘못된 설명 제거.
3. 15종별 준비자료·입력 순서·제외 범위·관련 가이드 및 계산기 링크를 서버 HTML로 제공. 새 URL을 만들지 않고 기존 canonical 보강.
4. 목록에 이름·목적 검색과 결과 개수 표시, 12종 공통 페이지에 입력/사용법 바로가기.
5. 부가세·종합소득세 입력을 첫 번째로 배치. 신고 진단과 세무사비 비교는 선택해서 펼침.
6. 공통 결과 금액 모바일 줄바꿈·숫자 정렬·변경 알림 개선. 증여·상속증여·기장 결과에도 알림 추가.
7. 계산기 전용 `/calculator-sitemap.xml` (목록+15종), robots에 안내, 실제 변경일로 lastmod 제공. 전체 목록 ItemList 구조화 데이터 추가. FAQ는 화면에 표시되는 내용과 일치시키고 계산 목적과 무관한 입점 FAQ 제거.
8. 기존 노후월급 계측은 유지. 다른 14종에는 `calculator_view`, 첫 입력 `calculator_start` 추가. 공통 결과·증여·상속증여·기장·예금적금은 실제 화면 노출 `calculator_result_visible` 추가. 기존 `calculator_result_view`는 계산 직후 이벤트여서 별도로 유지. 추가 계측에는 입력 금액·결과 금액·연락처를 보내지 않는다. 로그인한 운영자 등 내부 트래픽은 기존 정책으로 제외된다.

## 트래픽 운영 순서와 판정

1. 검색엔진 발견: 배포 후 계산기 전용 사이트맵과 변경 URL 제출. Google은 Search Console, Naver/Bing은 IndexNow 및 로그인 가능한 웹마스터 도구. 접수와 실제 색인은 다름.
2. 7~14일 뒤 같은 URL 집합의 색인/크롤링 시점·노출을 비교. 날짜는 관찰 계획이며 자동 실행을 새로 만들지 않음.
3. 28일간 검색어·랜딩별 노출→클릭→입력 시작→결과 열람을 비교. 노출이 없으면 재크롤링/콘텐츠 차별성부터, 노출은 있는데 클릭이 없으면 검색 의도와 제목부터, 입력 후 이탈이면 해당 계산기 UX부터 수정.
4. 우선 보강할 유입 글: 부가세 포함/별도 계산 예시, 주휴수당 시간별 예시, 연금·IRP 추가납입 예시. 기존 글과 중복 확인 후 실제 계산기 결과와 일치하는 수치로 보강. 대량 유사 페이지를 추가하는 방식은 피함.
5. 기존 네이버 블로그에서 관련 계산기로 자연스러운 안내는 유효한 배포 후보. 이번 요청만으로 커뮤니티 홍보나 외부 계정의 새 글 발행을 실행하지 않음.

무료 검색 유입을 보장할 수 없다. 사이트맵·구조화 데이터는 발견/이해를 돕는 수단이며 검색엔진의 색인·순위 선택을 강제하지 않는다.
