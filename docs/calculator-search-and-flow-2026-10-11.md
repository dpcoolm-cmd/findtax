## 트래픽 운영 순서와 판정

1. 검색엔진 발견: 배포 후 계산기 전용 사이트맵과 변경 URL 제출. Google은 Search Console, Naver/Bing은 IndexNow 및 로그인 가능한 웹마스터 도구. 접수와 실제 색인은 다름.
2. 7~14일 뒤 같은 URL 집합의 색인/크롤링 시점·노출을 비교. 날짜는 관찰 계획이며 자동 실행을 새로 만들지 않음.
3. 28일간 검색어·랜딩별 노출→클릭→입력 시작→결과 열람을 비교. 노출이 없으면 재크롤링/콘텐츠 차별성부터, 노출은 있는데 클릭이 없으면 검색 의도와 제목부터, 입력 후 이탈이면 해당 계산기 UX부터 수정.
4. 우선 보강할 유입 글: 부가세 포함/별도 계산 예시, 주휴수당 시간별 예시, 연금·IRP 추가납입 예시. 기존 글과 중복 확인 후 실제 계산기 결과와 일치하는 수치로 보강. 대량 유사 페이지를 추가하는 방식은 피함.
5. 기존 네이버 블로그에서 관련 계산기로 자연스러운 안내는 유효한 배포 후보. 이번 요청만으로 커뮤니티 홍보나 외부 계정의 새 글 발행을 실행하지 않음.

무료 검색 유입을 보장할 수 없다. 사이트맵·구조화 데이터는 발견/이해를 돕는 수단이며 검색엔진의 색인·순위 선택을 강제하지 않는다.
