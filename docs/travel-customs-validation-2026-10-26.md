# 여행자 관세 계산기 검증 기록 (2026-10-26)

## 관세환율 API

- 공식 명세: https://www.data.go.kr/data/15101230/openapi.do
- 요청: `aplyBgnDt=YYYYMMDD`, `weekFxrtTpcd=2`(수입), 서버 전용 `serviceKey`.
- 응답 필드: `resultCode`, `currSgn`, `fxrt`, `aplyBgnDt`, `imexTp`.
- 공공데이터포털 개발계정 활용신청이 2026-10-26 승인됐다(화면상 만료일 2028-10-26). 인증키는 Git 제외 대상인 로컬 `.env.local`에 서버 전용으로 저장했다. Vercel 운영 환경변수에도 서버 전용으로 등록했으며 값은 문서·Git에 기록하지 않았다.
- 2026-10-26 로컬 실제 호출 HTTP 200: 적용 시작일 `20261025`, USD `1330.52`, JPY `8.4277`. 같은 날 관세청 공식 계산기 화면의 USD `1,330.52원`, JPY `8.4277원`과 일치했다. 따라서 두 값은 각각 **1달러당 원화**, **1엔당 원화**로 확인했다.
- `/api/travel-customs/rates`는 성공 시 `verified_import_rates`와 `KRW_per_1_currency_unit`을 반환한다. 키 누락 또는 응답·통화·일자·범위 이상 시 오류 상태를 반환하고, 아직 발표되지 않은 미래 입국일 환율은 제공하지 않는다. 계산기 화면은 미래 입국일에 **현재 공개된 환율**을 별도로 조회해 적용 시작일·USD/JPY 값·출처를 표시한다. JPY 입력은 같은 기간의 `JPY→KRW÷USD→KRW`로 USD 상당액을 구한다. 미래 입국일의 JPY 판정은 `현재 환율 기준 참고`로 표시하고 0원 세액이나 확정 절약액을 내지 않는다. 환율을 조회할 수 없으면 JPY 물품의 판정은 `추가 확인 필요`가 된다. 환율을 품목별 예상세액 산출에는 아직 사용하지 않는다.

## 관세청 공식 계산기 비교

출처: https://www.customs.go.kr/kcs/ad/tax/ItemTaxCalculation.do

2026-10-26 화면에서 성인 1인·동반 가족 없음·일반물품 1개·달러 입력으로 관찰했다. 공식 화면은 자진신고 관세 감면을 적용한다고 안내한다. 당시 화면 환율은 USD 1,330.52원, JPY 8.4277원이었다. **환율 적용기간은 화면에서 확인하지 못했으므로 아래 세액을 고정 테스트 정답으로 쓰지 않는다.**

| 품목 | 입력 | 공식 면세/과세액 | 공식 예상세액 | FindTax |
| --- | ---: | ---: | ---: | --- |
| 기타물품 | $800 | 과세 0원 | 0원 | 한도 이내, 입력품 기준 0원 |
| 기타물품 | $801 | 과세 1,330원 | 140원 | 한도 초과, 세액 보류 |
| 기타물품 | $900 | 과세 133,052원 | 13,970원 | 한도 초과, 세액 보류 |
| 의류·섬유제품 | $900 | 과세 133,052원 | 16,760원 | 한도 초과, 세액 보류 |

초과 세액은 물품 분류·공제·자진신고 감면·환율·절사 순서가 모두 확인될 때까지 숫자로 제공하지 않는다. 위 비교는 현재 한도 판정의 방향과 세액 보류가 적절한지 확인한 기록이다.

## 모바일 점검

로컬 Chrome 헤드리스의 실제 뷰포트 360px, 390px, 768px, 1280px에서 한국 입국·일본 쇼핑 탭을 확인했다. 네 크기 모두 문서 가로 넘침과 화면 밖으로 잘린 입력 요소가 없었다. 탭 전환, 입국일·$800 입력 후 `면세 범위 내` 결과, 2026-10-25 적용 USD/JPY 환율 문구 표시, 210,000엔 입력 후 `한도 초과`를 확인했다. 360px의 미래 입국일·100,000엔 입력은 `현재 환율 기준 면세 범위 내 예상 · 입국일 재확인`과 현재 환율 적용 시작일을 표시했으며, 확정 세액 `0원`은 표시하지 않았다. 360px 첫 화면 스크린샷을 육안 확인했다. 이는 브라우저 뷰포트 검증이며 실물 휴대전화의 OS별 날짜 입력 UI까지 검증한 것은 아니다.

- 공개 화면의 USD 801 입력에서 초과 판정은 정상이나 Google 자동광고가 결과 영역을 가리는 현상을 발견했다. 관세 계산기 경로에서 자동광고 스크립트 로드를 제외하고, 계산기 목록의 해당 링크는 전체 문서 이동으로 변경했다. 이 변경은 재배포 후 공개 화면에서 다시 확인한다.
- 숫자 예상세액은 일반물품 초과분의 공제·세율·절사 및 자진신고 감면 산식을 더 검증하기 전 제공하지 않는다. 일본 환급 가능액은 실제 지급액으로 간주하지 않는다.
