# 네이버 블로그 초안 작성 가이드

FindTax 글을 네이버 블로그용 요약 글로 다시 쓴다. 업로드는 사람이 직접 한다(자동 게시하지 않음).
초안은 `docs/naver-drafts/YYYY-MM-DD-{주제}.txt`에 저장한다.

## 왜 하는가
2026-10 기준 FindTax의 실제 유입 중 가장 큰 채널이 네이버 블로그 링크(m.blog.naver.com)다. 블로그 글 하나가 발행되면 방문이 며칠 동안 늘었다가 빠진다. 꾸준히 올리면 유입이 쌓인다.

## 무엇을 쓰나
- 최근 발행된 FindTax 글 중 **검색량이 큰 상시 주제**(증여·양도·퇴직금·주휴수당·4대보험·종소세·부가세)와 **2~6주 안의 시즌 주제**를 고른다.
- FindTax 글을 복사하지 않는다. 같은 사실을 네이버 독자에게 말하듯 **새로 쓴다**(중복 콘텐츠 방지).
- 계산기가 있는 주제면 계산기로, 없으면 해당 블로그 글로 링크한다.

## 형식 (네이버 SmartEditor, 순수 텍스트)
- 첫 줄 `제목: ...` (검색어를 앞쪽에, 30자 안팎)
- 본문 900~1,500자, 소제목은 `■ 소제목`, 목록은 `·`
- 링크 1개: `👉 {설명}: https://findtax.kr/...?utm_source=naver&utm_medium=blog&utm_campaign={주제-영문}`
- 마지막에 `※ 일반적인 기준이에요...` 한 줄, 그다음 해시태그 15개 내외
- 이모지는 링크 앞 👉만 쓴다

## 어투 (Worth.IT 보이스)
- 공감으로 시작: "~잖아요", "이런 적 있잖아요" → 바로 핵심. 서론 길게 쓰지 않는다.
- 종결어미를 섞는다: ~거든요 / ~더라고요 / ~잖아요 / ~죠 / ~는 거예요 / ~는 셈이에요. "~해요"는 전체의 30% 이하.
- 짧은 문장 2개 뒤에 긴 설명 문장 1개처럼 리듬을 만든다. 짧은 문장 3개 이상 연속 금지.
- 섹션당 의문문 최대 1개. 대시(—)로 전환을 만든다.
- 구체적 숫자를 쓴다("비싸다" 대신 "132만 원").
- 쓰지 말 것: "~해야 합니다", "꼭 알아야 할", "완벽한 방법", "전문가가 추천하는", "~하는 것이 좋습니다", 불릿 남발, "무조건", "100% 환급", "무료 상담".
- 글 어딘가에 저장 유도 한 줄("저장해두면 ~ 때 다시 보게 되더라고요").

## 정확성
- 수치·기한·요건은 FindTax 원문과 그 원문의 sources(법제처·국세청 등)로 확인한 것만 쓴다.
- 원문에서 오류를 발견하면 초안에 그대로 옮기지 말고 보고에 남긴다.
