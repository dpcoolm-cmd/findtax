AS-IS → TO-BE

오늘 바뀐 핵심

단순히 화면을 추가한 것이 아니라 사용자가 세금을 판단하고, 실행하고, 완료하는 흐름까지 연결했습니다.

서비스 정체성 반영 완료

As-is

여러 세목의 예상 금액을 보여주는 계산기·세무사 검색 사이트

→

To-be

세금 계산 후 직접 처리 여부, 준비자료, 신고기한과 다음 행동까지 안내하는 플랫폼

핵심 타깃 반영 완료

As-is

누구나 이용하는 범용 세금 계산 서비스로 보여 고객상이 불명확

→

To-be

1인사업자, 부업러, 온라인·글로벌 셀러와 가족 증여 준비 고객을 전면에 제시

증여세 반영 완료

As-is

관계와 금액을 기준으로 예상 증여세를 계산하는 단발성 도구

→

To-be

10년 공제 한도, 과거 증여, 신고기한, 복잡도, 직접 신고 여부까지 하나의 케이스로 관리

1인사업자 반영 완료

As-is

부가세·종소세 등 세목별 계산기가 분리되어 전체 의무와 일정을 파악하기 어려움

→

To-be

사업 상태에 맞춰 부가세·종소세·원천세·지급명세서와 다음 일정을 연간 운영표로 제공

연금·IRP 반영 완료

As-is

연봉과 납입액만으로 공제 효과를 보여 주는 단순 계산기

→

To-be

직장인·사업자·혼합소득, 현금흐름, ISA 전환을 함께 보고 실제 잔여 한도 안에서만 납입 순서를 제안

셀러 대응 반영 완료

As-is

구매대행·역직구 관련 콘텐츠는 있었지만 첫 화면에서 발견하기 어려움

→

To-be

히어로에서 온라인·글로벌 셀러를 명시하고 업종별 증빙·세금 위험도 진단으로 바로 연결

실행 관리 반영 완료

As-is

계산 결과를 확인한 뒤 사용자가 다음 절차를 별도로 찾아야 함

→

To-be

직접 신고·전문가 진행 선택, 준비서류 체크, 홈택스 이동, 완료 처리까지 연속 제공

회원·재방문 반영 완료

As-is

비회원 계산 중심이라 이전 판단 결과와 진행 상태를 이어 보기 어려움

→

To-be

비회원으로 시작한 뒤 필요할 때 로그인하여 내 세금에 케이스와 진행 상태를 저장

관리자 인사이트 반영 완료

As-is

방문·상담 데이터는 보이지만 사용자가 계산 후 실제로 무엇을 했는지 파악하기 어려움

→

To-be

세금 유형별 생성, 저장, 방식 선택, 자료 준비, 완료 전환율을 관리자 화면에서 확인

히어로 반영 완료

As-is

“세금 문제, 계산부터”라는 범용 메시지와 계산기·세무사 찾기 중심 CTA

→

To-be

사업·판매 세금과 다음 할 일을 강조하고 사업 정리·셀러 진단 CTA와 세 가지 상황 선택 제공

USER FLOW

새로운 핵심 흐름

가입을 먼저 강요하지 않고 가치를 경험한 뒤 저장하도록 설계해 초기 이탈을 줄였습니다.

01 · 진입 상황 선택

사업·부업, 글로벌 판매, 가족 증여 중 현재 상황을 선택합니다.

02 · 진단 계산과 판단

금액, 한도, 복잡도와 다음 신고 일정을 확인합니다.

03 · 선택 직접 또는 전문가

직접 처리할지 세무사 검토를 받을지 판단합니다.

04 · 실행 자료와 신고

준비서류를 체크하고 홈택스 또는 상담으로 이동합니다.

05 · 관리 저장과 완료

내 세금에 저장하고 완료 상태와 향후 일정을 관리합니다.

SYSTEM & DATA

화면 뒤에서 바뀐 것

사용자 기능이 실제 운영 데이터로 남도록 서버와 데이터베이스까지 함께 확장했습니다.

  • 할 일·서류·진행 방식·완료 상태 공통 관리

Supabase

  • 관리자 유형별 퍼널 집계 함수 적용
  • 케이스 생성 RPC를 서버 서비스 역할 전용으로 제한

관리자 운영

  • 증여세·1인사업자·연금 유형별 생성 건수
  • 직접 신고·전문가 진행 선택 비율
  • 자료 준비와 완료 도달률 확인

아직 남은 개선 후보

아래 항목은 오늘 논의했지만 아직 코드에 반영하지 않았습니다. 기능 안정화 후 순서대로 진행하는 것이 좋습니다.

우선순위 1

히어로 결과 예시

예상 세금, 신고기한, 직접 신고 가능 여부를 첫 화면에서 미리 보여 전환 이유를 강화합니다.

우선순위 2

광고 노출 시점

쿠팡 고정 배너가 첫 진단을 가리지 않도록 결과 확인 이후 노출 또는 접기 기능을 검토합니다.

우선순위 3

교차 서비스 배너

Home-atoz 링크는 유지하되 FindTax 첫 행동보다 강하게 보이지 않도록 대비와 높이를 조정합니다.
